# 🧠 SYNAPSE: Nexus of Mind

**SYNAPSE: Nexus of Mind** is a sleek web & Android game designed to challenge your logic, focus, and memory through progressive cognitive puzzles in a futuristic dark-mode UI. 

---

## ✨ Features
- **Cross-Platform:** Seamless performance on both desktop browsers and Android mobile devices.
- **Cognitive Challenges:** Progressive levels, memory tests, and logic puzzles to sharpen your mental focus.
- **Sleek UI/UX:** Built with a minimalist dark-mode aesthetic and immersive audio-visual cues.
